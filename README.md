# Seller Service

Этот сервис предназначен для пользования продавцами. Здесь продавцы регистрируются, ищут и добавляют товары, изменяют складские остатки товаров. Является мастер-системой в части данных о товарах (помимо складских остатков, эти данные хранятся в buyer-service) и продавцах.

## База данных

**Имя БД:** `seller_database`  
**Схема:** `seller_application`

### Таблица: product_category

Категории товаров. Изначально в ней должны быть следующие категории товаров:
- Пищевые товары - FOOD_PRODUCTS
- Непищевые товары - NON-FOOD_PRODUCTS

Далее список может быть расширен. Эта таблица является справочником, заполняется миграцией при релизе сразу в обоих сервисах.

## Архитектура безопасности

Подразумевается, что авторизация и аутентификация пользователей будет реализована в отдельном сервисе.

Запросы к buyer-service и seller-service не будут поступать непосредственно, они будут проксироваться через gateway_service.

**Последовательность:**
1. В gateway_service пользователь (покупатель или продавец) авторизируется и аутентифицируется, выполняет нужный ему запрос;
2. gateway_service направляет запрос в нужный сервис, обогащая его хэдером `X-Auth-User-ID`, куда помещается UUID пользователя;
3. При обработке запроса данные о пользователе берутся из хэдера `X-Auth-User-ID`.

## API Endpoints

### Контроллер продавцов

| Метод | Эндпоинт | Описание | X-Auth-User-ID |
|-------|----------|----------|----------------|
| POST | /api/v1/sellers | создание нового пользователя | ❌ |
| DELETE | /api/v1/sellers/{id} | дезактивация пользователя | ❌ |
| GET | /api/v1/sellers | получение общей информации о пользователях по набору фильтров | ❌ |
| GET | /api/v1/sellers/{id} | получение подробной информации о конкретном пользователе | ❌ |
| GET | /api/v1/sellers/me | получение подробной информации пользователем о самом себе | ✅ |

---

### Контроллер товаров

| Метод | Эндпоинт | Описание | X-Auth-User-ID |
|-------|----------|----------|----------------|
| GET | /api/v1/products | поиск товаров по фильтрам | ❌ |
| GET | /api/v1/products/{id} | получение детальной информации по товару | ❌ |
| POST | /api/v1/products | добавление нового товара | ❌ |
| DELETE | /api/v1/products/{id} | дезактивация товара | ❌ |
| PUT | /api/v1/products/{id} | изменение товара (название, описание, категории) | ❌ |

> *Примечание: Искать товары могут все, а запросы на изменение товаров может отправлять только администрация.*
